# Licensing status

The official Warajevo download page states:

> Since February 2006, Warajevo is Open Source, with GPL license.

The official revision history states that release 2.52 was identical to 2.51,
but the licence was changed to GPL and the source was made freely available.

However, the public pages do not state:

- the exact GNU GPL version;
- whether the grant is “version N only” or “version N or later”;
- whether every file in all four source archives has identical licensing;
- whether any bundled third-party files have separate terms.

## Repository policy

1. Preserve every original copyright and licence notice.
2. Do not replace ambiguous upstream notices with a guessed GPL version.
3. Do not add a generic `LICENSE` file until the source archives have been
   inspected for an authoritative version.
4. Record archive hashes and provenance in `docs/UPSTREAM.md`.
5. Exclude ZX Spectrum ROM images unless their redistribution rights are clear.
6. Mark all new repository-authored files with an explicit modern licence only
   after deciding how that interacts with the upstream GPL-covered code.

This document records evidence; it is not legal advice.
