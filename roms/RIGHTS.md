# Spectrum ROM Rights and Provenance

## Preserved files

This directory preserves the original Sinclair ZX Spectrum ROM images used by
the 48K and 128K machines:

- `spectrum-48k/48.rom`
- `spectrum-128k/128-0.rom`
- `spectrum-128k/128-1.rom`

Each file is exactly 16,384 bytes.

## Source

The ROM images were downloaded individually from the World of Spectrum /
Spectrum Computing archive listings, not extracted from Warajevo's ROM-only
partial package.

## Redistribution basis

Amstrad has publicly permitted redistribution of the Spectrum ROM code for
emulator use, provided the copyright notices remain intact. Amstrad retains
copyright in the ROM code.

These ROM images are preserved here under that redistribution permission.

## Integrity

Authoritative SHA-256 checksums are recorded in `SHA256SUMS.txt`.

The files must remain unmodified. Any derived or patched ROM must be stored
separately and clearly identified as modified.

## Scope

This preservation set intentionally excludes:

- Timex ROMs;
- Interface ROMs;
- peripheral ROMs;
- cartridge ROMs;
- third-party ROM replacements;
- Warajevo ROM-only partial-package archives.
